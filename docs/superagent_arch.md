# 每个 cwd 的 Superagent —— 精简方案

## 目标

- 每个 cwd 增加一个 superagent。
- superagent 默认使用 cc gui。
- superagent 能管理该 cwd 下各个 session：
  - 让其停止
  - 获取 session 进度
  - 自动追加提示

## 事件机制

- 事件先分类：用户操作、AI block、结束等。
- 所有事件都进入队列。
- 事件进入队列后不会立刻处理，而是等待触发后组合发送。
- 组合后一次性发给 superagent。

## 使能与触发

- superagent 根据用户的要求，自动在 Vibe IDE 内使能要接收的事件。
- 使能后，只要使能的事件发生，就触发一次处理。这些事件开关要显示出来，同时ui用户也能随时开关。
- 触发时，把当前队列中的所有事件一次性组合发给 superagent。
- 未被使能的事件也入队，但不触发superagent的即刻处理。触发时都是发给superagent的。

## 运行中插话

- superagent 正在处理事件时，如果又来了新的、需要监听的事件并触发：
  - 继续组合所有新事件
  - 以插话方式发给 superagent
  - 不等它空闲

## 流程

```
事件产生 → 分类 → 入队（全部事件）
                    │
             使能的事件发生
                    │
                 触发
                    │
        组合队列中的全部事件
                    │
        superagent 正在处理？
          ├─ 是 → 插话继续组合
          └─ 否 → 一次性处理
```

## 任务拆解

1. **Superagent 生命周期**
   - 与 cwd 绑定
   - 默认 cc gui

2. **事件分类**
   - 定义分类：用户操作、AI block、结束等
   - 明确各类下的事件，包含任务结束、人的 git 回退

3. **事件队列**
   - 所有事件入队
   - 事件组合

4. **事件使能**
   - superagent 根据用户要求自动使能
   - 在 Vibe IDE 内生效

5. **触发处理**
   - 使能的事件发生即触发
   - 一次性处理队列全部消息

6. **运行中插话**
   - busy 时继续组合新事件
   - 插话发给 superagent

7. **会话管理**
   - 停止 cwd 下 session
   - 获取 session 进度
   - 自动追加提示

# Superagent UI 设计

## 入口与承载

- 承载位置：直接放在 cwd 里。
- cwd 的 SVG：
  - hover 时增加特效。
  - 点击不再是重命名，改为启动 superagent。
- cwd 的整理菜单：
  - 改为启动 superagent。
  - 启动后菜单变成关闭 superagent。

## 启动后的交互

- 点击 cwd 的空白位置，切换到 superagent 窗口。

## 事件触发开关

- 放在**中间栏**。
- 开关显示事件类别：用户操作、AI block、结束等。
- UI 用户可随时开关。
- 开关状态与 superagent 自动使能保持同步。

## 中栏 AiTab

- 对话区只负责对话派活。
- 不需要考虑回退场景。

## 消息显示

- 用户消息：右侧气泡。
- 事件：中间，可展开信息。
- 回复：左侧圆角标签。
