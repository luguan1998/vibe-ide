# Vibe IDE Docs

Welcome to **Vibe IDE** documentation.

## Quick Start

Run the development server:

```bash
npm run dev
```

<Button variant="primary">Get Started</Button>

## Components

The IDE is composed of several key components:

| Component | Description |
|-----------|-------------|
| Terminal  | Native xterm.js terminal |
| GitTab    | Git integration panel |
| FileTab   | File browser |
| SearchPanel | Content search |
| DiffViewer | Monaco editor/diff |
